Quick Setup (Firebase Console):
  1. Create a project in Firebase Console, then add a Web app (</>) and copy its firebaseConfig.
  2. In Firebase Console, open Build → Firestore Database → Create database (start in test mode).
  3. Paste your firebaseConfig below and click Connect & Sync.
  4. Click Download index.html (GitHub Pages) to get a ready-to-upload file with your Firebase config built in.
